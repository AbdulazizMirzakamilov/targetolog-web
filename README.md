Высокопроизводительная трёхъязычная веб-платформа и конверсионный лендинг-портфолио, разработанные с нуля для презентации услуг и кейсов в сфере performance-маркетинга и таргетированной рекламы.

Проект спроектирован с упором на максимальную скорость загрузки (100/100 по Google PageSpeed), чистую типографику, нулевой рантайм-оверхед от тяжёлых JS-фреймворков и бессерверную архитектуру Cloudflare Functions.

---

## 🎯 Архитектура и возможности

* **Индивидуальный SSG-движок:** Быстрая предварительная компиляция статических страниц без использования сторонних фреймворков.
* **Трёхъязычная локализация (RU / UZ / EN):** Полноценная поддержка трёх языков с учётом региональных стандартов типографики, мета-тегов `hreflang` и канонических URL.
* **Динамические отзывы клиентов:** Асинхронная подгрузка проверенных отзывов через серверные API-эндпоинты Cloudflare Functions.
* **Панель модерации:** Защищённый интерфейс управления входящими отзывами с серверной аутентификацией.
* **Адаптивный Mobile-First интерфейс:** Полная оптимизация под мобильные устройства, включая модальные окна, мобильное меню и просмотр подтверждающих скриншотов.

---

## 🚀 Технический стек

* **Zero Framework Overhead:** Чистый семантический HTML5 и Vanilla JS без тяжёлых внешних зависимостей.
* **Tailwind CSS v4:** Современный движок стилей с компиляцией через `@tailwindcss/cli` в оптимизированный бандл.
* **Cloudflare Platform:**
  * Cloudflare Pages: глобальная CDN-доставка статики и заголовки безопасности HTTP.
  * Cloudflare Functions: изолированные бессерверные API-эндпоинты.
  * Cloudflare KV: быстрое распределённое хранение проверенных данных.
* **Оптимизация медиа:** Все скриншоты и изображения переведены в формат WebP со снижением размера более чем на 70%.
* **Самохостинг шрифтов:** Шрифты `Manrope` и `JetBrains Mono` предзагружаются с сервера без сторонних блокирующих запросов.

## 📁 Структура проекта

```text
├── public/                      # Статические ресурсы (шрифты, WebP-медиа, favicon)
├── scripts/                     # Скрипты сборки и конвертации медиа
├── src/
│   ├── css/                     # Стили Tailwind CSS v4
│   ├── data/                    # Данные кейсов и метрик
│   ├── js/                      # Клиентские скрипты
│   ├── locales/                 # Локализационные словари (RU, UZ, EN)
│   └── template/                # Шаблоны страниц и компонентов
├── site.config.json             # Конфигурация проекта
└── package.json                 # Зависимости и скрипты сборки
```
